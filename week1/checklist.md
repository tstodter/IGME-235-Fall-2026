# Week 1 Checklist - IGME 235

## Get Set Up

- **Join the Slack workspace** - Check myCourses for the invitation link

- **Post an introduction** in #235-intros-and-games

- **Review the syllabus** - Available in the myCourses Content area

- **Obtain the textbook** or make sure you can access it in [O'Reilly Electronic Books](https://go.oreilly.com/rochester-institute-of-technology/library/view/-/9781491960196/?ar). Also check out the [companion website](https://learningwebdesign.com/).

- **Create a GitHub account** - Sign up for the [Student Developer Pack](https://education.github.com/pack) if needed

## Readings

- **Chapter 1** of _Learning Web Design_: "Getting Started in Web Design"
- **Chapter 2**: "How the Web Works"

## Quizzes

- **Take the study quiz for Chapter 1**
- **Take the study quiz for Chapter 2**

## Tools to Install

- **Text editor** - VS Code recommended (with the Live Server extension)
- **FTP client** - FileZilla or WinSCP for uploading to banjo
- **Browsers** - Chrome and Firefox (get comfortable opening their developer tools)

## First Assignments

- **Upload a test file to banjo** - Prove your server access works; submit the URL in myCourses
- **Start the Custom 404 homework** - Create your directory structure on banjo

## Before Next Week

- **Complete the Custom 404 homework**
- **Finish all study quizzes**
- **Have your development environment working** - editor, FTP client, and browsers installed
